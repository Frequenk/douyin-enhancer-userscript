## 核心功能

### 1. 🚀 自动跳过

| 功能     | 说明                   |
| -------- | ---------------------- |
| 跳过直播 | 自动检测并跳过直播内容 |
| 跳过广告 | 自动识别并跳过广告视频 |

### 2. 🚫 内容屏蔽

| 功能          | 说明                                                              |
| ------------- | ----------------------------------------------------------------- |
| 🎯 多维度屏蔽 | 支持按**账号名称**、**视频简介**、**#话题标签**三种方式检测关键字 |
| 作者声明 | 位于关键字检测范围上方，包含“个人观点，仅供参考”“虚构演绎，仅供娱乐”“内容由 AI 生成”三个独立选项，默认均关闭；界面省略“作者声明：”前缀，识别时仅在官方标识内规范化空白及该前缀后精确匹配，兼容有、无前缀的显示形式 |
| 平台提示 | 位于作者声明下方，包含“疑似使用了 AI 生成技术，请谨慎甄别”“作品含 AI 生成内容”两个独立选项，默认均关闭，分别精确匹配对应官方提示，不匹配普通文案中的相同文字 |
| 🧩 范围细分   | 每个关键字可单独勾选名称、简介、标签；新关键字默认勾选全部范围    |
| 智能处理      | 可选"不感兴趣"(R键)告诉算法，或仅跳到下一个视频                   |
| 📁 导入/导出  | 新版 JSON 会包含关键字和独立范围；导入仍兼容旧版 TXT              |

工具栏原“账号屏蔽”更名为“内容屏蔽”，已有配置保留。作者声明和平台提示共五个选项分别保存，均跟随内容屏蔽总开关和“跳过时自动按 R 键”设置，不依赖关键字列表或三个关键字检测范围；命中后优先处理，同一条内容只触发一次，且不计入“关键字屏蔽”统计。关键字导入导出不包含这五个选项。

### 3. 📺 画质优化

| 功能              | 说明                                                                                                            |
| ----------------- | --------------------------------------------------------------------------------------------------------------- |
| 🔝 自动最高分辨率 | 智能选择当前视频可用的最高分辨率 (4K > 2K > 1080P...)                                                           |
| 🔒 锁定4K         | 找到4K视频后可自动关闭此功能，避免不必要的切换                                                                  |
| 📡 直播最高清     | 在 `live.douyin.com` 和 `www.douyin.com/root/live/*` 直播页工具栏提供最高清开关，自动切到可用最高画质后自动关闭 |
| 直播净化 | 支持从直播推荐页或短视频信息流进入的直播间。悬停直播工具栏的“直播净化”，通过滑动开关设置“弹幕开关”“送礼信息”“福袋口令”“屏蔽礼物特效”的进入默认值并记忆选择；初始值与抖音原生默认一致：“弹幕开关”“送礼信息”“福袋口令”开启，“屏蔽礼物特效”关闭，已保存的用户选择优先；进入直播间后在后台加载原生设置面板并应用默认值，无需手动悬停，初始化期间不显示弹窗，确认面板关闭后恢复正常悬停交互，不影响之后手动切换原生选项 |
| 分辨率筛选        | 只观看指定分辨率的视频，不符合的自动跳过                                                                        |

### 4. 🤖 AI智能筛选

| 功能        | 说明                                             |
| ----------- | ------------------------------------------------ |
| 🧠 内容识别 | 自定义想看的内容（如"风景"、"猫咪"），AI自动筛选 |
| 智能点赞    | 当AI判定为喜欢的内容时，可选择自动点赞(Z键)      |
| 快速决策    | 通过多时间点截图检测，实现快速精准判断           |
| 🔀 双服务商 | 支持 Ollama（本地部署）和智谱AI（在线）          |
| 🖼 图集支持 | 图片类型作品自动截取当前轮播图进行AI检测         |

### 5. 极速模式

| 功能        | 说明                                             |
| ----------- | ------------------------------------------------ |
| 🕒 定时切换 | 每个视频播放指定时间后自动切换，适合快速浏览     |
| 自定义时间  | 支持固定时间或随机时间模式 (1-3600秒)            |
| 🖼 图集支持 | 图片类型作品按挂钟时间计时，到点自动切换         |

### 6. 📊 数据统计

| 功能          | 说明                                               |
| ------------- | -------------------------------------------------- |
| 🧾 实时统计   | 工具栏胶囊展示今[数量][时长]，打开统计面板查看汇总 |
| 🗓 年度视图   | 年度热力图 + 月度柱状图（数量/时长）               |
| 📥📤 导入导出 | 支持数据导入/导出，方便备份与迁移                  |

### 7. 🎛 按钮设置

| 功能          | 说明                                                                   |
| ------------- | ---------------------------------------------------------------------- |
| 🔘 默认开关   | 可在工具栏打开设置弹窗，为每个功能单独设置默认开关状态                 |
| 👁 眼睛显隐   | 用眼睛图标单独控制按钮是否显示，统计胶囊等工具入口也支持单独显隐       |
| 🛡 隐藏保护   | 当按钮被设为隐藏时，会自动关闭默认开关；若想默认启用，会提示先展示按钮 |
| 🧹 自动清屏   | 支持给抖音原生清屏功能设置默认值，每条新视频自动触发一次（等同按 J）   |
| ⚡ 立即生效   | 保存后会立即同步当前会话，无需刷新页面                                 |
